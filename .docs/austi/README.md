# Austi

Austi is an app-first desktop environment for turning natural-language requests into durable,
local software. The agent helps create and revise an app, but repeated use happens through the
app itself rather than through another agent turn.

This directory documents the product principles that should guide Austi's design and engineering:

- [Core values](core-values.md)

These principles are decision criteria, not marketing copy. When implementation choices conflict,
prefer the option that better preserves durable user value, local ownership, explicit authority,
and deterministic execution.
